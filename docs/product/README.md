# Product Documentation Index

`PRD.md` is the short product contract. Read only the detail document relevant to the task.

| Task | Read |
|---|---|
| General product task | `PRD.md` only |
| Pricing editor or calculation UI | `pricing-model.md` |
| AI request/response or provider | `ai-contract.md` |
| Blueprint editor or renderer | `blueprint-schema.md` |
| Public quotation/blueprint/detail pages | `public-artifacts.md` |
| Contract UI | `contract-generator.md` |
| Security/signature/public tokens | `security-rules.md` |

Do not read every detail document unless the task crosses multiple domains.
